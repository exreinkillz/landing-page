# Landing Page Project

I built this project from scratch without relying on AI assistance to deeply understand the core concepts. This project is a milestone in my web development journey through **The Odin Project**.

---

##  Overview
The goal of this project was to replicate a given design mockup using **HTML5** and **CSS Flexbox**. It focuses on layout structure, container hierarchy, and visual accuracy on desktop screens.

## Built With
* **HTML5** – Semantic element structure (`<header>`, `<section>`, `<main>`, `<footer>`)
* **CSS3** – Pure CSS using Flexbox (`display: flex`, alignment properties, axes management)
* **Google Fonts** – Roboto font family

## 🧠 Key Takeaways & What I Learned
Through building and refactoring this project independently multiple times, I mastered:
* **The "Box Model" Mental Framework:** Breaking down complex UI designs into parent containers and direct child items before writing code.
* **Flexbox Direction & Axis Mechanics:** Understanding how `justify-content` and `align-items` shift based on `flex-direction: row` vs `column`.
* **Clean & Semantic HTML:** Writing structural markup without unnecessary `div` nesting.
* **Self-Reliance:** Solving layout bugs through trial, error, rather than quick-code generators.
